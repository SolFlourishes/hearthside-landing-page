# Neurodiversity Resources and Support

## 🏢 Foundational Organizations and Information Resources (ASD Focus)

| Resource/Organization | Purpose and Available Services |
| :--- | :--- |
| **Aspect (Autism Spectrum Australia)** | An organization using the "**a different brilliant®**" approach, which respects difference, builds skills based on strengths, develops autism-friendly environments, and supports respectful interactions. Services include Aspect Schools, Distance Education Program, Assessment and diagnosis, Therapy services, Adult Community Services, and professional development. |
